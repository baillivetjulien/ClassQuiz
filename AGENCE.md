# Version de l'Agence régionale de l'orientation et des métiers de Normandie

Ce dépôt est une version dérivée de [ClassQuiz](https://github.com/mawoka-myblock/ClassQuiz), logiciel libre de quiz en direct créé par Marlon W (Mawoka) et distribué sous licence [MPL 2.0](LICENSE). Il est adapté aux ateliers d'orientation de l'Agence : charte graphique, interface en français, slides illustrées, nuage de mots, avatars d'équipe, sources cliquables, bibliothèque partagée entre conseillères.

Les fichiers modifiés restent sous MPL 2.0 et leur code source est publié ici, sur la branche `agence`. La branche `master` suit le projet d'origine. Les corrections utiles à tous sont proposées au projet d'origine.
